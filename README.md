# JS-simple-coroutine

이 프로젝트는 자바스크립트에서 코루틴 개념을 흉내 내는 실험용 모듈입니다. 핵심 아이디어는 하나의 루프 안에서 여러 작업을 순환적으로 처리하고, 작업이 완료되면 집계되는 구조를 만드는 것입니다.

## 개요

코드에는 `setInterval` 기반의 루프와 작업 배열이 포함되어 있으며, `MainT`, `LowT`, `EndMain`, `EndLow` 같은 구조를 통해 작업의 라이프사이클을 추적합니다.

```js
let MainT = [];
let EndMain = {};
let LowT = [];
let EndLow = {};
```

이 구현은 실제 JS 코루틴 라이브러리라기보다, "작업을 큐에 넣고 반복 루프에서 처리하는 패턴"을 실험하는 예제에 가깝습니다.

## 핵심 아이디어

- 단일 루프에서 여러 작업을 관리
- 작업의 생성과 완료를 추적
- 우선순위가 낮은 작업과 메인 작업을 분리
- 간단한 상태 기반 스케줄링 구조를 시도

## 사용 방식

1. 프로젝트 폴더로 이동합니다.
   ```bash
   cd JS-simple-coroutine
   ```
2. 브라우저에서 `index.html`을 엽니다.
3. `index.js`의 로직을 통해 브라우저 콘솔 또는 페이지에서 동작을 확인합니다.

## 참고사항

- 이 코드는 "코루틴을 직접 구현한다"는 실험적 목적이 강합니다.
- 실제 서비스 코드로 적용하려면 더 명확한 상태 모델과 작업 스케줄링 분리가 필요합니다.
- 현재 구조는 학습용 데모와 프로토타입에 적합합니다.

## 학습 포인트

- 루프 기반 작업 처리
- 비동기 로직의 구조화
- 상태 추적과 타이머 기반 스케줄링
- 자바스크립트에서 운영체제적 패턴을 흉내 내는 방식
